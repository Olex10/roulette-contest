# Рулетка — конкурс (Cloudflare Workers + D1)

## Состояние проекта

Рабочая основа сайта и админки: регистрация ID с отдельным ключом доступа, одноразовые коды заявок, активация, ручное подтверждение администратором, начисление фишек, рейтинг и серии рулетки. Данные хранятся в Cloudflare D1. Конкурс **закрыт по умолчанию**. Контакт на старте: https://t.me/MK_Admin_XM.

**НЕ открывайте конкурс реальным участникам до завершения тестирования и проверки ниже.** Это первая версия, не прошедшая сквозное тестирование на развернутом Cloudflare. Не используйте реальные пополнения в тестах.

## Развёртывание

1. Создайте репозиторий GitHub и загрузите в него содержимое этой папки. Установите Node.js 20+ и выполните `npm install`.
2. Выполните `npx wrangler login` и `npx wrangler d1 create roulette-contest`. Скопируйте `database_id` из ответа в `wrangler.jsonc` вместо `REPLACE_WITH_D1_DATABASE_ID`.
3. Выполните `npm run db:remote` для создания таблиц в удалённой D1.
4. Выполните `npx wrangler secret put ADMIN_KEY` и введите длинный случайный пароль администратора (не храните его в GitHub).
5. Выполните `npm run deploy`. Откройте адрес Worker, `/admin.html` — панель администратора.
6. Для автопубликации свяжите репозиторий с Cloudflare Workers в панели Cloudflare (Workers & Pages → Create → Import repository). Настройте команду сборки `npm install` и команду развёртывания `npx wrangler deploy`; убедитесь, что проект использует `wrangler.jsonc`, D1 binding и Secret ADMIN_KEY.
7. В админке укажите реальные данные, проверьте работу на тестовом ID и только после всех проверок установите `contest_open=true`.

Локальная разработка: `npm run db:local`, затем `npx wrangler secret put ADMIN_KEY --env` не требуется; создайте локальный `.dev.vars` с `ADMIN_KEY=...` (не загружайте файл в GitHub). Запустите `npm run dev`.

## Важные правила и ограничения

- Владелец ID не подтверждается: код подтверждает **заявку и факт пополнения, проверенный администратором**, но не личность владельца игрового аккаунта. Не объявляйте его доказательством владения ID.
- Ключ доступа игрока показывается один раз при регистрации. Если он потерян, безопасный процесс восстановления ещё не реализован. **Не выдавайте ключ по одному только ID**.
- Уникальный код выдаётся при создании заявки, хранится только в виде хеша и повторно не показывается. После активации код нельзя активировать снова. Каждое новое пополнение — новая заявка и новый код.
- В админке подтверждайте только фактические пополнения. При сумме выше 10 000 ₽ число фишек вводится вручную. Важно: действующие пороги начисления на сайте описаны по *общей подтверждённой сумме ID*, а код сейчас начисляет по сумме *отдельной заявки*. До открытия конкурса нужно согласовать и реализовать правильный накопительный расчёт; иначе разбиение пополнения на несколько заявок меняет число фишек.
- Финальный «ВА-БАНК» пока **не реализован**. Кнопка `final_open` — настройка, не функциональность. До запуска требуется согласовать механику, сроки и призы ТОП-5.
- Для повышения надёжности до публичного запуска требуется аудит атомарности операций и гонок (особенно вращения и подтверждения заявок), нагрузочное тестирование, ограничение частоты запросов, восстановление доступа игрока, безопасная смена админ-ключа, политика хранения данных, защита от ботов и тестирование правил по возрасту/юрисдикции.
- Условия и допустимость конкурса, пополнений и игровых механик в выбранном ГЕО требуют отдельной проверки. Фишки не являются денежным балансом.

## Тестовый сценарий

1. В админке задайте тестовые сроки, контакт и кассиров; откройте конкурс **только в закрытом тестовом окружении**.
2. Создайте тестовый ID, сохраните ключ доступа, создайте заявку и код.
3. Активируйте код, проверьте статус `pending`, повторную активацию (должна быть отклонена).
4. Подтвердите тестовую заявку, проверьте баланс, серию и рейтинг; повторное подтверждение должно быть отклонено.
5. Проверьте проигрыш, первый выигрыш, «забрать» и второй спин, повторный спин закрытой серии.
6. Создайте вторую заявку того же ID и проверьте независимость кода и начисления.
7. Проверьте мобильную версию и вход с другого устройства по ID + ключу.
